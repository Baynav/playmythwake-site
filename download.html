How to install

  1. Click Download for Windows and save Launcher.zip.
  2. Right-click the zip and choose Extract All. Pick a folder you'll keep, such as Documents\Mythwake. Keep all the files together: the launcher needs everything that comes out of the zip.
  3. Open the folder and run Launcher.exe. If Windows shows "Windows protected your PC", click More info, then Run anyway. (The launcher isn't code-signed yet, so Windows doesn't know it.)
  4. The launcher downloads the game and starts it. It checks for updates every time, so you're always on the latest version.
  5. On the login screen, create an account with your email address. We'll email you a 6-digit code to confirm it.
  6. Make your character and step into the world.

What you need

SystemWindows 10 or 11, 64-bit
InternetNeeded: Mythwake is an online game
